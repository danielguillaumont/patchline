Status: first coded responsive design candidate, **not** final visual approval. Original three desktop wireframes and mobile treatments described in `spectral-index-wireframes.md` remain a future sign-off gate. The first implementation intentionally ships Atlas and Methods with an Explorer placeholder; no unsupported KEV timeline or CVE-level data.

2. Three-item underlined navigation, selected state, always-visible data-classification rail.
3. Asymmetric hero: left Archivo display; right ultraviolet M03 coverage signal with count reconciliation.

5. Large summary quantiles, citron interpretation note, dark editorial footer.
